# matriz-ie22375
Matriz de consolidado IE 22375 Santa Rosa de los Molinos


### Competencias transversales de Secundaria por Tutor

El flujo y la compatibilidad están documentados en [docs/tutor-transversales-pr67.md](docs/tutor-transversales-pr67.md). Admin configura las asignaciones de aportes y las tutorías; el Tutor toma y envía la decisión oficial. Los snapshots antiguos de Admin se conservan como historia, no como resultados oficiales del nuevo flujo. Tras un futuro merge, este cambio requiere el workflow oficial de Deploy Apps Script; no se debe desplegar manualmente.
